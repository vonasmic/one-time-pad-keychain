# Utimaco HSM simulator

Place the Utimaco SecurityServer / u.trust GP HSM Simulator SDK here.
The SDK is proprietary (Utimaco license) and is **not committed**.

Unzip so this directory is the SDK root (not an extra nested version folder).

Expected layout:

```
Software/Linux/Administration/csadm
Software/Linux/Administration/key/ADMIN_SIM.key
Software/Windows/Administration/csadm.exe
Software/Windows/Administration/key/ADMIN_SIM.key
```

See [JAVA_TLS_TEST/README.md](../../JAVA_TLS_TEST/README.md#hsm-setup) for start and `csadm` init. `./run-all.sh` does not start the Windows simulator.
